# /paper-numbers — 원고 수치 검증

원고에 적힌 숫자 하나하나가 **지금 이 순간의 데이터에서 재현되는지** 확인한다.
재현 안 되는 숫자는 셋 중 하나다: 데이터가 갱신됐거나, 다른 지표에서 가져왔거나, 애초에 틀렸다.

## 왜 이게 필요한가

원고 수치는 조용히 썩는다. 셀이 추가되고, 패턴이 빠지고, 파서가 고쳐지면 모든 집계가 움직이는데
본문 문장은 그대로 남는다. 컴파일도 되고 읽어도 말이 되므로 **아무것도 실패하지 않는다.**

실제로 잡힌 사례:

| 유형 | 사례 |
|---|---|
| **지표 혼합** | "패턴 스팬 0.027, 모델 스팬 0.107, 셀 표준편차 0.098" — 첫 숫자는 shape, 나머지 둘은 scale에서 온 것. 한 지표로 읽으면 주장이 성립하지 않았고 shape에서는 부호가 뒤집혔다 |
| **갱신 누락** | 본문 0.046인데 데이터는 0.047 (셀이 늘어난 뒤 재계산 안 됨) |
| **개수 불일치** | 캡션 "네 패턴"인데 실제 다섯 |
| **출처 오류** | "handheld sequence"라고 썼으나 깊이맵 무효픽셀 0.000%로 합성 궤적이었음 |

## 절차

1. **대상 확정** — 인자로 경로가 오면 그것, 없으면 작업 디렉토리에서 `.tex`를 찾는다.
   Overleaf 프로젝트면 `git -C <dir> status`로 커밋 안 된 변경이 있는지 먼저 본다.

2. **수치 추출** — `.tex`에서 숫자를 담은 문장을 전부 뽑는다.
   `$0.047$`, `0.047`, `\SI{4.8}{\meter}`, 표 셀, 캡션 안까지 포함.
   **무시할 것**: 절/그림/표 번호, 인용 연도, 식 번호, 페이지 수.

3. **각 수치를 셋으로 분류**한다:

   | 분류 | 뜻 | 조치 |
   |---|---|---|
   | **생성됨** | 스크립트가 만든 표·그림 안의 값 | 스크립트를 다시 돌려 대조 |
   | **본문 인용** | 산문에 손으로 적힌 값 | 데이터에서 재계산해 대조 |
   | **설계 상수** | 반지름·간격·시야각 등 | 설정 파일·코드와 대조 |

4. **재현** — 각 값을 실제로 계산한다. **원고를 믿고 검산하지 말 것.**
   데이터에서 독립적으로 뽑은 다음 비교한다. 원고 숫자를 먼저 보면 그 숫자에 맞는 필터를 무의식중에 고르게 된다.

5. **지표 혼합 검사** — 한 문장에 여러 숫자가 있으면 **전부 같은 지표·같은 부분집합에서 왔는지** 확인한다.
   이게 가장 잡기 어렵다. 각 숫자가 개별로는 데이터에 실재하기 때문에 하나씩 검산하면 전부 통과한다.
   문장 단위로 "이 숫자들이 같은 표의 같은 행에서 나오는가"를 물어야 보인다.

6. **보고** — 표로:

   ```
   | 위치 | 원고 | 재현 | 판정 |
   |---|---|---|---|
   | §V-A 2문단 | 0.046 | 0.047 | 갱신 필요 |
   | 초록 3문장 | 0.027 / 0.107 | shape / scale | 지표 혼합 |
   | Fig.2 캡션 | 네 패턴 | 다섯 | 불일치 |
   ```

   **일치하는 것도 몇 개인지 밝힌다.** "3건 발견"만 쓰면 나머지를 확인했는지 알 수 없다.

## 규칙

- **고치지 말고 보고한다.** 지표 혼합은 어느 쪽이 맞는지가 저자의 결정이다. 명시적으로 요청받으면 고친다.
- **재현 불가는 불일치와 다르다.** 데이터가 없어 확인 못 한 값은 따로 표시한다. 조용히 통과시키지 않는다.
- **부호와 방향을 본다.** 크기가 맞아도 "A가 B보다 크다"가 뒤집혔으면 더 심각하다.
- **반올림 차이는 불일치가 아니다.** 0.0468 → 0.047은 정상. 유효숫자 규칙이 절마다 다르면 그건 별도 지적.
- 값이 **여러 곳에 반복**되면 전부 찾는다. 초록·본문·결론에 같은 수가 있고 한 곳만 갱신된 경우가 흔하다.
